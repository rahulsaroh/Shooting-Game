# DeadAim 3D Animated Character Models Guide (`/public/models/`)

This directory holds the animated `.glb` (glTF 2.0 binary) 3D models loaded by `src/game/ZombieManager.ts` via Three.js `GLTFLoader`, cloned per enemy instance using `SkeletonUtils.clone`, and driven by `THREE.AnimationMixer`.

> **Built-in Default GLBs & Safe Fallback:**
> DeadAim includes pre-built animated `.glb` files in each theme folder out of the box (generated by `npx tsx scripts/generate-assets.ts`). Furthermore, if any `.glb` file is missing or fails to load, `ZombieManager.ts` logs a warning to the browser console and automatically falls back to the procedural box/capsule zombie rig so the game **never crashes**.

## 2. Expected Animation Clip Names

Each `.glb` file should embed the following named `AnimationClip` tracks (configured per zombie type in `shared/themes.json` under `animations`):

| Clip Key in `themes.json` | Default Clip Name in `.glb` | Required / Optional | Playback Behavior |
|---|---|---|---|
| `walk` | `"Walk"` | **Required** | Loops continuously (`THREE.LoopRepeat`) while advancing toward the barricade. |
| `attack` | `"Attack"` | **Required** | Loops (`THREE.LoopRepeat`) when clawing the barricade at point-blank range. |
| `death` | `"Death"` | **Required** | Plays once (`THREE.LoopOnce`, `clampWhenFinished = true`). Corpse is removed when finished. |
| `hit` | `"Hit"` | *Optional* | Plays once (`THREE.LoopOnce`) when taking bullet damage. |
| `idle` | `"Idle"` | *Optional* | Plays when frozen by a Cryo power-up or idling. |

*Note: `ZombieManager.ts` first looks up the exact clip name specified in `shared/themes.json`, and also supports case-insensitive substring matching (e.g., `"Zombie_Walk"` matches `walk`) for convenience.*

## 4. How to Convert Mixamo FBX Files into a Single Animated `.glb`

When downloading from Mixamo, you typically get one `.fbx` filewith the Character Mesh + Skin (`With Skin`), and separate `.fbx` files for each animation (`Without Skin`). Follow these steps to pack them into a single `.glb` file:

### Option 1: Using Blender (Free, Recommended)
1. **Import Character Base:**
   - Open Blender (`File -> New -> General`, delete default cube).
   - Go to `File -> Import -> FBX (.fbx)` and import your character downloaded **With Skin** (e.g., `Zombie_Walk.fbx`).
2. **Import Additional Animation Clips:**
   - Go to `File -> Import -> FBX (.fbx)` and import `Zombie_Attack.fbx`, `Zombie_Death.fbx`, `Zombie_Hit.fbx`, and `Zombie_Idle.fbx` (downloaded **Without Skin**).
3. **Rename Actions in the Dope Sheet / Action Editor:**
   - Switch the bottom timeline editor to **Dope Sheet**, then change its mode dropdown to **Action Editor**.
   - Select each imported action and rename them cleanly to:
     - `Walk`
     - `Attack`
     - `Death`
     - `Hit`
     - `Idle`
   - Click the **Push Down** (or **Stash**) button next to each action so Blender's **NLA (Nonlinear Animation)** tracks retain all 5 animations on the main Armature.
   - Delete the extra duplicate armatures imported from the `Without Skin` FBX files.
4. **Normalize Scale & Orientation:**
   - Ensure the character's feet rest at `Y = 0` and faces `+Z` (toward the camera).
   - Select the Armature, press `Ctrl + A -> All Transforms`.
5. **Export as `.glb`:**
   - Go to `File -> Export -> glTF 2.0 (.glb/.gltf)`.
   - Set **Format** to `glTF Binary (.glb)`.
   - Under **Animation**, ensure **Animation** is checked and **Animation Mode** is set to `Actions` or `NLA Tracks`.
   - Save to `/public/models/<theme>/zombie_<type>.glb`.

### Option 2: Command-Line Conversion (`FBX2glTF` + `gltf-transform`)
```bash
# Convert a single FBX to GLB using FBX2glTF
FBX2glTF -b -i Zombie_Normal.fbx -o public/models/classic/zombie_normal.glb

# Optimize & compress textures/meshes for 60 FPS web rendering
npx @gltf-transform/cli optimize public/models/classic/zombie_normal.glb public/models/classic/zombie_normal.glb
```

## 5. Verifying Hitbox Alignment on the TV Screen

Because gameplay hit detection on the server (`server/GameEngine.ts`) uses explicit **Head Sphere + Body Capsule** hitboxes defined in `shared/config.ts` (`ZOMBIE_HITBOXES`) rather than raycasting against triangles:
1. Start the game (`npm run dev`) and open the TV view.
2. Press **`H`** on your keyboard at any time during a wave.
3. Yellow (`Head Sphere`) and Cyan (`Body Capsule`) 3D wireframes will render around every zombie so you can verify that your `.glb` model's `scale` in `shared/themes.json` lines up with the server hitboxes.
